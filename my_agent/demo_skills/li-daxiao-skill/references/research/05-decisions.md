# 李大霄重大预测、市场判断与决策记录

> **研究说明**：本文档系统梳理李大霄（前英大证券首席经济学家，1964年生，2024年7月退休）的主要市场预测、顶底判断及事后验证情况。数据来源为公开报道和财经媒体，尽量区分"预测"（事前表态）与"事后诸葛亮"（事后叙述）。

---

## 一、著名底部预测全集

李大霄以给市场底部"命名"而闻名A股，据公开记录，他创造了超过十种"底"的称呼。以下按时间顺序排列：

### 1. 钻石底（2132点）

| 项目 | 内容 |
|------|------|
| **预测时间** | 2012年1月 |
| **具体点位** | 2132.63点（2012年1月6日低点） |
| **预测原话** | "2132点是钻石底"，认为市场已见底 |
| **事后结果** | **被击穿**。2012年7月跌破2100点，2012年12月跌至1949点，2013年6月28日最终探至1849点 |
| **李大霄回应** | 后来修正称钻石底仅适用于"优质公司"，并非全市场底部 |
| **验证** | 从2132到1849，下跌约13.2%，底部预测失败 |

**补充细节**：
- 2012年12月4日，指数跌至1949点时，他又发出"1949点是新中国底"的判断，但随后继续下跌
- 市场后来在2014年中才真正启动牛市，距离"钻石底"判断超过两年

### 2. 婴儿底（2850点）

| 项目 | 内容 |
|------|------|
| **预测时间** | 2015年8月26日 |
| **具体点位** | 2850点（2015年股灾后低点） |
| **预测背景** | 2015年6月12日沪指见顶5178点后，两个月内暴跌至2850点 |
| **事后结果** | **被击穿**。2016年1月18日下探至2844.7点，随后继续下跌至2638点 |
| **李大霄回应** | 重新定义为"婴儿底（2）"，称2844点是婴儿底2；后又下调至2638点 |
| **验证** | 从2850到2638，下跌约7.4%，原始婴儿底被击穿 |

**关键事件链**：
1. 2015年8月26日：宣布2850点为"婴儿底"
2. 2016年1月18日：沪指下探2844.7点，击穿婴儿底
3. 李大霄改称"婴儿底（2）"为2844点
4. 继续下跌后，又改称"婴儿底2"为3189.6点（2016年1月5日）
5. 最终2016年1月28日探至2638点才止跌

### 3. 婴儿底2（3189.6点）

| 项目 | 内容 |
|------|------|
| **提出时间** | 2016年1月5日 |
| **具体点位** | 3189.6点 |
| **事后结果** | **被击穿**。指数继续下跌至2638点 |

### 4. 儿童底（2691点）

| 项目 | 内容 |
|------|------|
| **首次提出** | 2017年12月（无初始具体点位） |
| **明确点位** | 2018年中期，称2691点为儿童底绝对极限 |
| **事后结果** | **被击穿**。2691点被快速突破，市场继续调整 |
| **背景** | 2018年贸易战背景下A股持续下跌 |

### 5. 少年底 / 青春底

| 项目 | 内容 |
|------|------|
| **提出时间** | 2019年 |
| **具体点位** | 少年底1：2440点；少年底2：2838点（后调整为2833/2822）；青春底：2733点 |
| **事后结果** | 少年底1（2440点）暂时守住；少年底2和青春底均被击穿 |

### 6. 其他命名的底部

## 二、顶部预测：地球顶（2015年）

这是李大霄预测记录中**最著名的一次成功判断**。

### 预测时间线

| 日期 | 上证指数 | 李大霄表态 |
|------|----------|------------|
| 2015年4月 | 突破4000点 | 开始提示风险，不建议普通投资者入市 |
| 2015年4月27日 | ~4400点 | 正式宣布"地球顶"成立 |
| 2015年5月1日 | ~4500点 | 标注4572点为顶部 |
| 2015年6月4日 | ~4900点 | 发微博"庄严宣布：地球顶成立了" |
| **2015年6月9日** | ~5100点 | 强调**5147.45点**为新"地球顶"，建议卖股买房 |
| **2015年6月12日** | **5178.19点** | **实际顶部确认** |
| 2015年8月26日 | 2850点 | 市场在两个多月内暴跌45% |

### 预测建议内容

李大霄在地球顶期间多次发出警告：
- "不要退保入市"
- "不要辞职炒股"
- "不要借钱炒股"
- "不要卖房炒股"
- "远离黑五类（小盘股、次新股、垃圾股、题材股、伪成长股）"

### 事后验证

- 上证指数从5178点跌至2850点，跌幅约45%
- 截至2023年，上证指数仍未回到5000点以上
- 这次预测被广泛认为是他职业生涯中**最准确的一次判断**

### 为什么这次对了？

分析认为其正确性来源：
1. 市场杠杆（融资融券、配资）明显过高，去杠杆趋势可见
2. 创业板估值极度泡沫化（63倍PE）
3. 他作为业内人士能观察到融资数据的异常膨胀

## 三、2020-2022年期间重大判断

### 1. "3000点是地平线"

| 项目 | 内容 |
|------|------|
| **核心观点** | 3000点将成为A股未来的"地平线"，不会再被跌破 |
| **提出时间** | 约2016-2017年间反复强调 |
| **事后验证** | **多次被击穿**。2018年10月跌至2449点，2022年4月跌至2863点，2024年2月跌至2635点 |
| **李大霄回应** | 坚持认为3000点是"坚实地平线"，被击穿是"极低概率"事件 |

### 2. "与3000点作最后告别"

| 项目 | 内容 |
|------|------|
| **时间** | 2022年11月4日 |
| **原话** | "A股与3000点作最后告别"，"这是反转不是反弹" |
| **事后验证** | **被击穿**。此后A股多次回到3000点以下，2024年初跌至2635点 |

### 3. "与3100点永不再见"

| 项目 | 内容 |
|------|------|
| **时间** | 约2023年10月 |
| **事后验证** | **被击穿**。2024年市场多次低于3100点 |

### 4. "四个大底"（2024年2月）

| 项目 | 内容 |
|------|------|
| **时间** | 2024年2月1日 |
| **内容** | 声称市场同时出现"估值底、政策底、经济底、市场底"四个大底 |
| **背景** | A股在2024年2月初跌至2635点后反弹 |
| **事后验证** | 短期反弹后市场确有所回暖，但后续再次调整，"四底合一"判断过于乐观 |

## 四、2024-2026年最新预测

### 1. "真牛市来了"（2024年11月）

| 项目 | 内容 |
|------|------|
| **场合** | 2025网易经济学家年会 |
| **核心观点** | "中国股市第一次真正的到来了" |
| **论据** | 国债收益率约2.07%，沪深300股息率超3.36%，存在显著利差优势 |
| **点位判断** | "3400点不是终点，还是上升途中的驿站" |
| **预期** | 2025年有望迎来大规模资金入市，优质蓝筹股领涨 |

### 2. 2025年市场回顾与2026年展望

| 项目 | 内容 |
|------|------|
| **2025年低点** | 高于2024年的2635/2689点 |
| **2026年判断** | 市场低点将高于2025年（呈现底部抬升趋势） |
| **高点判断** | 4170-4197点构成三重顶 |
| **当前位置** | 3800点上方调整是"对4000点的夯实过程" |
| **投资主线** | 高股息蓝筹股可能是2026年主要投资方向 |

### 3. 防御策略转向（2026年1月起）

| 项目 | 内容 |
|------|------|
| **时间** | 2026年1月14日 |
| **建议** | 从"进攻"转向"防御"策略 |
| **具体建议** | "主动去杠杆、主动还钱" |
| **原因** | 美股见顶及全球市场回落的传导影响 |
| **4200点警告** | "4200点可能再也见不到了" |

### 4. 2026年3月市场解读

| 项目 | 内容 |
|------|------|
| **调整原因** | 外围因素（美伊冲突升级导致国际局势紧张）+ 美股见顶传导 |
| **性质判断** | 不是牛市终结，而是阶段性调整 |
| **4000点** | 当前调整是"夯实4000点"的过程 |

## 五、事后反思与自我纠正

### 1. 关于预测偏差的公开表态

李大霄对预测失误的态度可以概括为：

- **承认短期预测受多因素干扰**：他曾表示"预测会受到多种因素甚至是不可抗力的影响而发生偏差"
- **坚持鲜明表态优于含糊其辞**：认为模棱两两会浪费读者时间，"鲜明的观点会错，而错会挨骂"
- **强调长期价值逻辑**：反复表示投资者不应依赖点位猜测，而应聚焦长期价值投资

### 2. 2015年股灾周年反思

在2016年股灾一周年活动中，李大霄参与了"对去年5178点时的自己说句话"的讨论：
- 核心反思是"降杠杆"和"减仓"
- 承认虽然判断了顶部，但对市场下跌的惨烈程度仍估计不足

### 3. 关于"钻石底"的修正

对于2012年"钻石底"判断过早的问题：
- 他承认判断过于乐观，导致"挨了三年骂"
- 后来修正为钻石底仅适用于"优质公司"，而非全市场

### 4. 关于"婴儿底"被击穿

- 面对2850点被击穿，他没有承认判断错误，而是重新定义了"婴儿底（2）"
- 这种"移动目标"的做法被市场广泛调侃

## 六、言行一致/不一致案例分析

### 一致案例

1. **始终倡导价值投资**：从早期到退休，一直坚持"做好人、买好股、得好报"的理念
2. **反对杠杆炒股**：在2015年地球顶期间明确警告不要借钱炒股，这一建议事后被证明极其正确
3. **看多中国核心资产**：长期看好低估值的蓝筹股，这一方向性判断长期来看有一定道理

### 不一致案例

1. **底部不断"升级"**：
   - 钻石底（2132）被破 -> 不认错，改称适用于"优质公司"
   - 婴儿底（2850）被破 -> 升级为婴儿底2（3189.6）
   - 婴儿底2被破 -> 市场最终跌至2638
   - 儿童底（2691）被破 -> 继续发明新底部名称

2. **"3000点地平线"论反复被打脸**：
   - 2017年前后称3000点是地平线
   - 2018年跌至2449
   - 2022年称"与3000点最后告别"
   - 2024年跌至2635
   - 2024年9月后称"3000点是坚实地平线"

3. **"小牛香味"与"真牛市"的判断**：
   - 多次表示"闻到小牛香味"，但市场后续表现经常不及预期
   - 2024年2月称"四底合一"，之后市场再次调整

## 七、监管事件

### 2020年3月被深圳证监局约谈

| 项目 | 内容 |
|------|------|
| **时间** | 2020年3月20日 |
| **监管方** | 深圳证监局 |
| **原因** | 通过新浪微博、微信公众号公开发表证券投资分析意见，但部分意见未能提供研究报告依据 |
| **违规性质** | 未能充分遵循客观、专业、审慎原则 |
| **违反法规** | 《证券公司和证券投资基金管理公司合规管理办法》《发布证券研究报告暂行规定》 |
| **处理结果** | 监管谈话（约谈） |
| **后续影响** | 之后一段时间内减少了各类"底部"预测的公开发布 |

### 被约谈前的导火索

- 在港股暴跌期间仍发表乐观言论
- 频繁使用微博等社交媒体发布缺乏研究报告支撑的市场判断
- 被质疑其预测缺乏客观依据，过于主观

## 八、个人投资行为

### 已知信息

1. **第一只股票**：深宝安（现"中国宝安"），但具体买入时间和盈亏情况未公开披露

2. **投资理念**：
   - 推崇价值投资，用"余钱"投资
   - 建议投资者"先买基金后买股票"，"先学习后投资"
   - 反对使用杠杆
   - 提出"正金字塔"建仓法
   - 认为"亏钱最多的往往不是熊市，而是牛市"

3. **未公开的信息**：
   - **个人持仓**：从未完整公开过个人股票账户持仓
   - **投资收益率**：未公开过个人投资组合的业绩记录
   - **自身是否跟从建议**：无法验证

### 关键局限

> 作为券商首席经济学家，李大霄的言论更多属于"市场观点"而非"个人投资实操"。他本人从未像某些投资者（如胡锡进）那样公开自己的实盘操作和盈亏。因此，其"言行一致性"中的"行"这一面，缺乏可验证的数据。

## 九、综合评估

### 预测准确率概览

根据多家媒体的梳理统计：

| 类别 | 表现 |
|------|------|
| **底部预测** | 绝大多数被击穿。钻石底、婴儿底、儿童底等均未守住 |
| **顶部预测** | 2015年"地球顶"判断基本正确，是其最成功的预测 |
| **方向性判断** | 长期看多A股核心资产的方向性判断有一定道理，但时机和点位经常偏差较大 |
| **短期预测** | 准确率普遍较低，多次出现"打脸"情况 |

### 公众评价两极分化

- **支持者认为**：他是A股少有的敢于鲜明表态的分析师，长期方向判断有价值，2015年逃顶建议救了很多人
- **批评者认为**：他不断发明新"底部"名称来掩饰预测错误，点位预测经常失败，被戏称为"反向指标"

### 一个客观的视角

1. **预测本身就很难**：巴菲特也明确表示不应该预测短期市场点位
2. **永远看多也是一种策略**：长期来看，A股核心资产确实有投资价值，永远看多的人偶尔也会碰对
3. **"地球顶"确实有价值**：2015年的逃顶建议是实质性地帮助了投资者
4. **但频繁预测点位确实存在问题**：不断调整"底部"定义削弱了其可信度
5. **被监管约谈反映了行业规范问题**：公开发表缺乏研究支撑的投资意见确实不合规
